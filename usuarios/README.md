# Usuarios

En esta sección aprenderás cómo gestionar a las personas que utilizan Vambe dentro de tu empresa.

Una correcta configuración de usuarios es clave para asegurar una operación ordenada, segura y eficiente. Aquí encontrarás guías para crear usuarios, asignar roles y configurar notificaciones según las necesidades de tu equipo.

Recientemente, hemos mejorado la gestión de permisos para ofrecerte mayor control y una experiencia más fluida. Esto incluye una refactorización de los permisos de analíticas, permitiendo una asignación más granular, y una interfaz optimizada para facilitar la configuración de accesos por rol.
