#### ¿Cómo apagar la IA?

Si necesitas que tus asistentes dejen de responder automáticamente, puedes desactivar la inteligencia artificial. El apagado es inmediato e impide la automatización de todos tus chats, así que úsalo solo cuando sea necesario.

{% stepper %}
{% step %}
**Ve a Ajustes de IA**

En el menú lateral izquierdo, entra a **Asistente** y luego haz clic en **Ajustes de IA**.
{% endstep %}

{% step %}
**Abre Disponibilidad**

Dentro de Ajustes de IA, selecciona la pestaña **Disponibilidad**.
{% endstep %}

{% step %}
**Desactiva la inteligencia artificial**

Abajo, en **Desactivar inteligencia artificial en Vambe**, verás el control **Estado IA** con las opciones **Activado** y **Desactivado**. Haz clic en **Desactivado** para apagar la IA.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Para volver a encender la IA, repite los pasos y deja el **Estado IA** en **Activado**.
{% endhint %}
